Retrieval demo

These are real rankings, not illustrations. Each query is encoded once by the frozen CLAP text encoder and scored against the held-out test set by cosine similarity. The only difference between the two columns is whether the audio embedding is frozen CLAP or ResiCLAP.

Each result is a real recording of an object being struck. The name is the struck object — the thing making the sound, not a target. The held-out objects (Mug (ceramic), Bin (plastic), Flowerpot (small ceramic), Vase (wood), Spatula (metal)) were not seen during training, so the same name recurs often. Individual recordings differ by strike point and microphone position, both shown beneath each name. Two recordings of the same object can therefore sound quite different, which is exactly the distinction these queries are asking the model to make.

The ranked recordings are deliberately subtle: they are natural impacts from the same material, separated only by brightness, attack or decay. To make the listening task clear, brightness and attack queries begin with an exaggerated same-recording calibration pair using the strongest transform in the curation sweep. These calibration clips teach the direction of the property; they are not retrieval results and do not enter any reported metric. Decay uses natural extremes because synthetic decay transformations did not pass the curation checks. Headphones help considerably.

Try a query

All 24 evaluation queries are available. The shortcuts below show the three largest improvements and, for balance, the query where ResiCLAP helps least.

A result counts as relevant when it matches the queried material and falls on the correct side of that property's distribution among sounds of the same material — the same category-relative criterion used in the paper. Improvements are not uniform: some queries gain a great deal, others not at all. Rankings come from the seed-7 checkpoint, while the tables elsewhere on this site report means over seeds 7, 17 and 27, so a single query here may differ from the averaged figure.
